macOS installation

安装 Markdown Writing

当前版本仅面向 Apple Silicon Mac。按照以下步骤下载、安装并完成首次启动。

macOS installation 系统要求 安装步骤 首次启动 后续更新 故障排查

系统要求

下载前请确认设备符合要求。目前不提供 Intel Mac、Windows 或 Linux 版本。

Apple Silicon 芯片

支持 M1、M2、M3、M4 及后续 M 系列芯片。

macOS

使用当前受支持的 macOS 版本，并保持系统更新。

未签名构建

首次打开时，macOS 可能要求你在系统设置中确认。

安装步骤

01
下载安装包

从官网或 GitHub Releases 下载文件名包含 arm64 或 apple-silicon 的版本。

02
解压或打开 DMG

如果下载的是 ZIP，请先解压；如果下载的是 DMG，请双击打开。

03
移动到应用程序

将 Markdown Writing 拖入“应用程序”文件夹，再从该位置启动。

04
确认首次启动

如果系统阻止打开，请在“系统设置 → 隐私与安全性”中允许本次打开。

首次启动

第一次启动不需要登录，也不会要求上传文档。你可以打开本地文件夹，或先创建一篇新文档。

关于“未验证的开发者”

这是未签名构建可能出现的提示。只应从项目官网或官方 GitHub Releases 下载安装包。

后续更新

应用内的设置页可以检查版本。官网更新记录会同步 GitHub Releases 的版本和说明。

打开 GitHub Releases

故障排查

  • 如果提示“应用已损坏”，请重新下载，并确认解压后的应用位于“应用程序”目录。
  • 如果应用无法打开，请确认设备使用 Apple Silicon，而不是 Intel 处理器。
  • 问题持续存在时，请在 GitHub Issues 中附上 macOS 版本、芯片型号和完整提示。
