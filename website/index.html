为长时间写作而设计

安静的界面，清晰的取舍。

Markdown Writing 不试图成为所有工具的集合。它只处理文档、编辑、保存和导出，并且把每一件事做得可预期。

本地文件优先

文档以 Markdown 文件保存在自己的文件夹里，不被锁进平台，也不依赖网络。

块编辑与源码并存

在富文本视图里自然书写，需要时切回源文，结构始终由用户掌握。

文档树和大纲

按文件夹管理稿件，点击大纲快速定位标题，让长文依然容易巡航。

稳定的自动保存

保存请求按顺序执行，写入使用临时文件和原子替换，降低异常中断的风险。

多格式导出

支持 Markdown、纯文本、PNG、PDF 和 Word 可打开的文档格式。

内容安全边界

渲染内容经过净化，桌面文件操作限制在用户授权的目录和打开过的文件。
