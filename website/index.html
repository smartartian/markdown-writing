为长期写作而设计

功能不堆叠，每一层都围绕文档。

从输入、组织、恢复到交付，每一项能力都对应真实写作流程中的一步。

块编辑与源码并存

在结构化视图中自然书写，需要精确控制时立即切回 Markdown 源文。支持选择映射、组合输入和模型级撤销重做。

查找与替换

在当前文档中查找、切换匹配项、替换单个结果或全部替换，并支持区分大小写。

文档树与大纲

按目录组织稿件，通过最近文档快速返回，并用大纲在长文中稳定巡航。

一份内容，多种交付

保留 Markdown 原文件，并按需要导出纯文本、PNG、PDF 或 Word 可打开的文档格式。

同一工作区，四种气质

主题不是换一层颜色，而是重排整个工作环境。

Paper、Sepia、Graphite、Ocean 都包含亮色与暗色版本。系统模式可以为亮暗环境分别选择主题。

JSON 用户主题

导入、复制、导出和删除自己的主题配置，预览会跟随当前编辑器令牌。

数据安全不是附加项

先保证不丢，再谈功能。

从原子写入到崩溃恢复，所有写盘路径都围绕同一原则设计：不让内容在写入途中丢失。
